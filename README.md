# 阅间图书馆座位预约系统

## 本地运行

需要 Node.js 18 或更高版本。在项目目录执行：

```bash
npm start
```

浏览器打开 `http://localhost:3000/`，管理员后台打开 `http://localhost:3000/admin.html`。

同一 Wi-Fi 或局域网内的其他电脑，请把 `localhost` 换成本机的 IPv4 地址，例如 `http://192.168.1.20:3000/`。运行服务的电脑必须保持开机，Windows 防火墙需要允许 Node.js 通过专用网络。

## 已实现的联动

- 学生端提交的预约进入共享数据文件；
- 管理员后台可以看到预约记录并取消预约；
- 管理员可以切换阅览室开放状态；
- 管理员可以把座位置为维修中或恢复可预约；
- 后台统计预约数、座位使用率和开放阅览室数量；
- 学生端和管理端共用登录会话与预约接口。

正式上线前应将 JSON 数据存储替换为 MySQL，并修改默认密码、启用 HTTPS 和正式账号体系。

## Railway 部署

本项目使用 `npm start` 启动，Railway 会自动读取 `PORT` 环境变量。将项目推送到 GitHub 后，在 Railway 中选择该仓库并部署即可。

免费方案适合课程设计演示。当前数据保存在 `data.json`，服务重新部署或重启后可能恢复初始数据；正式使用时建议改用 Railway PostgreSQL 或 MySQL。
